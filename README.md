# Insight Creativo para Flyer — Marketing Lab

Tercer módulo de la metodología:
**Contexto → Buyer Persona → Insight → Mensaje y emoción → Rutas creativas → Flyer**

## Incluye
- Recuperación de contexto y objetivos.
- Síntesis del Buyer Persona.
- Construcción de una tensión e hipótesis de insight.
- PIENSE / SIENTA / HAGA.
- Promesa y razones para creer.
- Generación local de 3 rutas creativas editables.
- Ejemplo Reset Night.
- Guardado automático.
- Descarga de brief creativo en PDF.

## GitHub Pages
1. Crea un repositorio, por ejemplo `insight-flyer`.
2. Sube `index.html`, `styles.css`, `app.js` y `README.md`.
3. Settings → Pages.
4. Deploy from a branch.
5. `main` + `/ (root)`.
